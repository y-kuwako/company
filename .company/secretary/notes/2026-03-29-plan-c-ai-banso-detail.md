# プランC: AI導入伴走サービス 詳細事業計画

## エグゼクティブサマリー

- **サービス名案**: AI Banso（仮）
- **コンセプト**: 中小企業のAI導入を「診断→ツール→定着」までワンストップで伴走
- **ターゲット**: 従業員30〜300名の中小企業（AI導入意欲はあるが社内にAI人材がいない）
- **収益モデル**: 初期コンサルフィー + SaaS月額 + 月額コンサルフィーのハイブリッド
- **損益分岐点**: 12〜14ヶ月目（顧客数8〜10社時点）
- **3年目売上目標**: 年間約1.2億円

---

## 1. MVP設計

### 1-1. サービス全体像（3ステップ）

```
Step 1: AI導入診断（初期コンサル）
  ↓ 2〜3週間
Step 2: ツール導入・カスタマイズ（SaaS提供）
  ↓ 1〜2週間
Step 3: 定着支援（月次コンサル+SaaS継続利用）
  ↓ 継続
```

### 1-2. SaaS部分（MVP機能）

MVPでは「すぐに成果が見える業務」に絞る。

| 機能 | 内容 | 技術要素 |
|------|------|----------|
| **AI業務診断ダッシュボード** | 業務一覧を入力→AI化の優先度・ROI概算を自動算出 | GPT-4o API + 独自スコアリング |
| **文書作成AI** | 議事録・メール・報告書テンプレートにAIを組み込み | GPT-4o API + RAG |
| **社内FAQ/ナレッジbot** | 社内ドキュメントをアップロード→チャットで質問回答 | RAG (Embedding + Vector DB) |
| **利用状況ダッシュボード** | 誰がどの機能をどれだけ使ったか可視化（定着度の指標） | 自社開発（ログ集計） |

**MVP対象外（将来追加）**:
- ワークフロー自動化（Zapier的機能）
- Slack/Teams連携による自動ナレッジ蓄積
- 業種特化テンプレート
- マルチエージェント対応

### 1-3. コンサル部分のサービス内容

#### Step 1: AI導入診断（初期コンサル）- 3回のセッション

| 回 | 内容 | 成果物 |
|----|------|--------|
| 第1回（2h） | 現状業務ヒアリング。業務フロー・課題の棚卸し | 業務一覧シート |
| 第2回（2h） | AI化候補の優先度付け。ROI試算 | AI導入ロードマップ |
| 第3回（1h） | 導入計画の合意。ツール設定方針の確定 | 導入計画書・KPI設定 |

#### Step 2: ツール導入・セットアップ支援（1〜2週間）

- SaaS環境のセットアップ
- 社内ドキュメントのアップロード・RAG設定
- テンプレートのカスタマイズ（業務に合わせた文書テンプレート）
- 管理者向けトレーニング（2h × 1回）

#### Step 3: 定着支援（月次コンサル）

| 頻度 | 内容 |
|------|------|
| 月1回（1.5h） | 利用状況レビュー + 活用改善提案 |
| 随時 | Slackチャンネルでの質問対応（営業時間内） |
| 四半期1回（2h） | AI活用の拡大検討（新業務への適用、新機能の提案） |

| リソース | 内容 | 期間 | 概算コスト |

## 3. リスクと対策

### リスク1: コンサルのスケーラビリティ問題

**内容**: コンサル部分が属人的で、顧客数が増えると品質維持が困難になる。1人が担当できる顧客数は10〜15社が限界。

**対策**:
- **SaaSで自動化できる部分を段階的に拡大**（利用状況レポート自動生成、AIによるセルフ改善提案）
- **コンサルの型化**（ヒアリングシート・診断レポート・月次レビューのテンプレート化）
- **3段階の支援レベル**を設計（ハイタッチ/テックタッチ/セルフの切り分け）
  - 月10万円: ハイタッチ（月次1on1 + Slack）
  - 月5万円: テックタッチ（自動レポート + 四半期レビューのみ）
  - 月0円: セルフ（SaaS利用のみ）
- **20社到達時点でコンサル専任を1名採用**（年収500〜600万円）

### リスク2: AI APIコストの変動と利益率悪化

**内容**: OpenAI APIの価格変動や、顧客の利用量増加により、API費用が想定を超えるリスク。特にRAG（ナレッジbot）は利用量に比例してコストが増加する。

**対策**:
- **従量課金の上限設定**（顧客ごとに月間APIコールの上限を設定）
- **キャッシュ戦略**（よくある質問への回答をキャッシュし、API呼び出しを削減）
- **モデルの使い分け**（単純な質問はGPT-4o-mini、複雑な質問のみGPT-4oを使用）
- **ローカルモデルへの段階的移行**（顧客数30社超で自社モデルのファインチューニング検討）
- **価格設定にAPI費用のバッファを15%以上確保**

### リスク3: 顧客のAI活用が定着せず解約が増加

**内容**: ツールを導入しても「結局使われない」ケースは多い。中小企業では現場のITリテラシーにばらつきがあり、推進者が異動・退職すると利用が止まるリスク。

**対策**:
- **利用状況ダッシュボードで早期警告**（利用率低下を検知し、プロアクティブにフォロー）
- **「小さな成功体験」の設計**（導入初月は1つの業務だけにフォーカスし、明確な成果を出す）
- **複数の推進者を育成**（1社につき2〜3名のキーユーザーをトレーニング）
- **ROIの定量レポートを毎月提出**（「AIで月XX時間削減」を数値で見せる）
- **解約予兆スコアの開発**（利用頻度、ログイン頻度、質問数の減少をモニタリング）

## 4. 請負事業とのシナジー

### 4-1. 顧客パイプラインの相互活用

```
請負（大手） → AI導入伴走の実績・事例 → 営業資料・信用力の向上
                                          ↓
AI導入伴走（中小） → 業務理解が深まる → 請負案件の提案力向上
                   → 中小がスケールした際に請負開発案件に転換
```

- **請負クライアント（大手）からの紹介**: 大手の取引先・グループ会社の中小企業を紹介してもらう
- **AI伴走の顧客が成長**: 業務が拡大しカスタム開発が必要になった場合、請負として受注
- **実績の横展開**: 「大手A社のシステムを開発している会社が提供するAIサービス」は中小企業にとって信頼材料

### 4-2. 技術・ナレッジの共有

| 請負で得るもの | AI伴走に活かすもの |
|--------------|-----------------|
| 業界ごとの業務フロー知識 | 業種別AI導入テンプレート |
| エンタープライズの品質基準 | SaaSの品質・セキュリティ水準 |
| API連携の実装経験 | SaaS連携機能の開発 |
| プロジェクト管理ノウハウ | コンサルの型化・効率化 |

| AI伴走で得るもの | 請負に活かすもの |
|----------------|----------------|
| 中小企業の業務課題の肌感覚 | 大手向け提案時の「現場目線」 |
| AI活用のベストプラクティス | 請負案件へのAI機能組み込み提案 |
| SaaS開発・運用ノウハウ | 請負クライアントへのSaaS提案 |
| 自社プロダクトの実績 | 「開発だけでなくプロダクトも持つ会社」としてのブランディング |

### 4-3. リソース配分ルール

| フェーズ | 請負 : AI伴走 | 考え方 |
|---------|-------------|--------|
| MVP開発期（M1-3） | 80 : 20 | 請負の売上を維持しつつMVP開発 |
| 立ち上げ期（M4-9） | 70 : 30 | コンサル対応が増えるため徐々に比率を上げる |
| 成長期（M10-24） | 60 : 40 | AI伴走の売上が増加、専任メンバーを配置 |
| 拡大期（M25-36） | 50 : 50 | 両輪のバランス型に移行 |

### 4-4. 具体的なシナジーアクション

1. **請負の既存クライアントに「AI活用度診断」を無料提供** → 興味を持った企業の関連会社を紹介してもらう
2. **請負案件にAI機能を標準提案** → 「AI機能の保守・活用支援はAI伴走サービスで」とセットで受注
3. **AI伴走の知見を請負の見積もりに反映** → AI活用による工数削減を提案に組み込み、競争力を向上
4. **共通の技術基盤** → 請負で作ったRAGモジュールやAPI連携部品をSaaSに再利用（逆も同様）
